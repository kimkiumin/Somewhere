# 프로필 식이·알레르기 목록 근거

확인일: 2026-08-12

## 적용 원칙

식이 조건은 취향·종교·건강 제약이 섞일 수 있으므로 하나의 `채식` 선택으로 뭉뚱그리지 않는다. 채식 유형은 서로 다른 허용 범위를 갖는 선택값으로 저장하고, 할랄·코셔·저염은 추가 조건으로 함께 선택할 수 있게 한다.

알레르기는 안전 제약으로 취급한다. 추천 후보가 알레르기 원재료를 사용하거나 원재료·조리 정보가 확인되지 않으면 통과시키지 않는 것이 실제 서비스의 기준이다. 교차오염·혼입 가능성은 메뉴 원재료 데이터만으로 확정할 수 없으므로 장소 확인이 별도로 필요하다.

## 식이 조건 목록

식품안전나라의 채식 유형 안내를 기준으로 다음을 프로필 선택지로 사용한다.

| 저장값 | 표시명 | 의미 |
| --- | --- | --- |
| `vegan` | 비건 | 동물성 식품을 먹지 않음 |
| `lacto` | 락토 | 유제품 허용, 육류·생선·달걀 제외 |
| `ovo` | 오보 | 달걀 허용, 유제품·육류·생선 제외 |
| `lacto_ovo` | 락토-오보 | 유제품·달걀 허용, 육류·생선 제외 |
| `pesco` | 페스코 | 생선·어패류 허용, 육류·가금류 제외 |
| `pollo_pesco` | 폴로-페스코 | 생선·어패류·가금류 허용, 붉은 고기 제외 |
| `flexitarian` | 플렉시테리언 | 상황에 따라 육류 허용 |
| `halal` | 할랄 | 할랄 인증·조리 여부 확인 필요 |
| `kosher` | 코셔 | 코셔 기준·조리 여부 확인 필요 |
| `low_sodium` | 저염 | 나트륨 제한 메뉴 선호 |

기존 프로토타입에 저장된 모호한 `vegetarian` 값은 자동으로 특정 유형으로 추정하지 않는다. 기존 값이 있는 경우에만 `채식(세부 유형 미선택)`으로 보여주고 사용자가 구체화하게 한다.

## 알레르기 목록

식품의약품안전처 법령해석이 인용한 「식품 등의 표시·광고에 관한 법률 시행규칙」 별표 2의 표시 대상 19개를 그대로 사용한다.

1. 난류(가금류)
2. 우유
3. 메밀
4. 땅콩
5. 대두
6. 밀
7. 고등어
8. 게
9. 새우
10. 돼지고기
11. 복숭아
12. 토마토
13. 아황산류 — 최종제품 이산화황 10mg/kg 이상 조건
14. 호두
15. 닭고기
16. 쇠고기
17. 오징어
18. 조개류 — 굴·전복·홍합 포함
19. 잣

기존의 포괄적인 `견과류`와 `갑각류` 항목은 법정 원재료 단위와 맞지 않으므로 제거했다. 과거 `tree_nut` 값이 이미 저장된 경우에는 기존 설정 안내를 보여주고 호두·잣을 각각 확인하도록 한다.

## 프로토타입 한계

현재 프로토타입은 프로필 선택값을 추천 조건에 전달하는 단계다. 실제 서비스를 시작하려면 매장별 메뉴 원재료, 조리시설 혼입 가능성, 할랄·코셔 인증 상태, 저염 수치가 출처와 시점이 있는 데이터로 확인되어야 한다. 확인되지 않은 값을 안전하다고 표시하지 않는다.
