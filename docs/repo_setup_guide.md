# Repo Setup Guide

This guide explains how to set up the GitHub repository for Codex.

## 1. Create Repository

Recommended repository name:

```text
blind-compass-discovery
```

Recommended visibility:

```text
Private
```

## 2. Add This Missing-Docs Pack

Copy the files from this pack into the repository root:

```text
README.md
AGENTS.md
.gitignore

docs/prototype_notes.md
docs/repo_setup_guide.md
docs/codex_first_prompt.md
docs/ui_review_checklist.md

data/mock_destinations.json
prototype/.gitkeep
```

## 5. Codex Start Procedure

1. Connect Codex to this GitHub repository.
2. Start a new task.
3. Paste the prompt in `docs/codex_first_prompt.md`.
4. Let Codex build the v0.1 prototype in `/prototype`.
5. Review the diff before merging.
6. Bring screenshots or a summary back to the GPT project for UX critique.

## 6. What Not to Do in v0.1

Do not ask Codex to add:

- Maps
- Real GPS
- Real APIs
- Login
- Restaurant rankings
- Reviews or ratings
- Recommendation algorithms
- Hardware connection

Those belong to later validation stages.
