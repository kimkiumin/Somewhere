# Somewhere 앱 시퀀스 요약

## 핵심 흐름

```text
첫 실행 온보딩
→ 식이 조건·알레르기 프로필 설정
→ 식당 조건 입력
→ 한 번의 출발
→ 장소 탐색
→ 나침반 바늘 기반 도보 안내
→ 목적지 근처
→ 도착 및 정보 공개
→ 60분 이후 장소 반응
→ 완료
```

## 화면별 공개 원칙

1. 조건 화면에서는 식당, 일행 수, 최대 도보 시간, 1인 예산, 공개 수준을 정합니다.
2. 탐색 중에는 목적지 이름·주소·사진·리뷰를 숨깁니다.
3. 안내 중에는 나침반 바늘, 다음 행동, 다음 행동까지 거리, 전체 남은 거리를 보여줍니다.
4. `Stop`은 즉시 안내를 멈춘 뒤 목적지 정보 확인 이유를 묻습니다. 이유를 건너뛰고 확인할 수도 있습니다.
5. 도착하면 식당 이름을 크게 표시하고 사진, 건물명·층/호수, 추천한 이유, 후기 요약을 제공합니다. 주소와 구체적인 입구 위치는 제공하지 않습니다.
6. 도착 후 60분이 지나야 장소 반응을 남길 수 있습니다.

## 안전·복구 원칙

- 안내 중에는 직접적인 Reveal 버튼을 노출하지 않습니다.
- `Stop` 이후 확인 이유와 안내 종료 이유는 별도로 기록합니다.
- 경로·센서 신뢰도가 낮으면 나침반 바늘은 방향을 가리키지 않고 재계산 상태를 표시합니다.
- 새 추천은 자동으로 시작하지 않으며, 사용자가 조건을 확인하고 출발 버튼을 다시 눌러야 합니다.

상세 규칙은 [앱 시퀀스 본문](../blueprint/app_sequence.md)을 기준으로 합니다.
