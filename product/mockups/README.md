# Product Mockup Archive

This archive copies the 20 existing generated concept images into the product area so the physical-form evidence can be indexed without coupling it to app code.

The images are visual hypotheses only. They do not prove electronics, magnetic isolation, display readability, power, actuator behavior, safety, mass/balance, enclosure fit, or manufacturability. The source descriptions intentionally retain this limitation.

## Sets

- [`carabiner/`](assets/carabiner/) — ten Somewhere carabiner compass explorations.
- [`stopwatch/`](assets/stopwatch/) — ten Somewhere stopwatch-form compass explorations.
- [`catalog.md`](catalog.md) — stable per-asset IDs and source mapping.

## Copy provenance

Source files were copied from:

- `outputs/imagegen/somewhere-carabiner-exploration/`
- `outputs/imagegen/somewhere-stopwatch-exploration/`

The copied files are evidence snapshots, not a new claim that the generated concepts are approved final designs.
